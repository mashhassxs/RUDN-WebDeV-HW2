# Spec: Удаление карточки

## Способность
Система позволяет пользователю удалить карточку с доски.

## Триггер
Пользователь нажимает кнопку "Удалить" на карточке.

## Основной сценарий
1. Пользователь видит кнопку "Удалить" на каждой карточке
2. Пользователь нажимает кнопку "Удалить"
3. Система показывает диалог подтверждения: "Вы уверены, что хотите удалить карточку?"
4. Пользователь подтверждает удаление
5. Система отправляет DELETE-запрос на сервер
6. Система обновляет кэш карточек
7. Карточка исчезает с доски

## Альтернативный сценарий
4а. Пользователь отменяет удаление
5а. Ничего не происходит, карточка остаётся на доске

## Ограничения
- Удаление необратимо (нет корзины)
- Требуется подтверждение перед удалением
