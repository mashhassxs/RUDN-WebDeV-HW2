# Spec: Удаление карточки на сервере

## Способность
Сервер позволяет удалять карточку по ID через DELETE-запрос.

## Триггер
Клиент отправляет DELETE-запрос на /api/cards/:id

## Основной сценарий
1. Клиент отправляет DELETE /api/cards/1
2. Сервер находит карточку с id=1 в массиве cards
3. Сервер удаляет карточку из массива
4. Сервер возвращает статус 200 и JSON: { "message": "Карточка удалена", "id": "1" }

## Альтернативный сценарий
2а. Карточка с id=1 не найдена
# Spec: Удаление карточки на сервере

## Способность
Сервер позволяет удалять карточку по ID через DELETE-запрос.

## Триггер
Клиент отправляет DELETE-запрос на /api/cards/:id

## Основной сценарий
1. Клиент отправляет DELETE /api/cards/1
2. Сервер находит карточку с id=1 в массиве cards
3. Сервер удаляет карточку из массива
4. Сервер возвращает статус 200 и JSON: { "message": "Карточка удалена", "id": "1" }

## Альтернативный сценарий
2а. Карточка с id=1 не найдена
3а. Сервер возвращает статус 404 и JSON: { "error": "Карточка не найдена" }

## Обработка ошибок
- Неизвестный путь: возвращает JSON 404 { "error": "Маршрут не найден" }
- Внутренняя ошибка: error-middleware возвращает JSON 500 { "error": "Внутренняя ошибка сервера" }

## Статус-код успешного удаления
200 OK (выбрано как стандартный код для успешных операций с возвращаемым телом)
