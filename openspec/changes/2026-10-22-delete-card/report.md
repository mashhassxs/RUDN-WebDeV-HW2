## Технические детали

### Проблема с JSONPlaceholder
API jsonplaceholder.typicode.com не всегда корректно обрабатывает DELETE-запросы (ошибка Network Error). 

### Решение
Использовано оптимистичное обновление через `queryClient.setQueryData`:
- Карточка сразу удаляется из кэша React Query
- UI обновляется мгновенно
- DELETE-запрос отправляется в фоне (если не succeeds — не критично)
