# KAN-2: Удаление карточки

## Проблема
На доске нет способа убрать карточку — ни ошибочно созданную, ни просто ненужную. Один раз добавленная карточка остаётся навсегда.

## Решение
Добавить кнопку "Удалить" в каждую карточку. При клике появляется подтверждение, после чего карточка удаляется с сервера и исчезает с доски.

## Технические детали
- Использовать DELETE-запрос к API (по аналогии с GET в BoardPage)
- После удаления обновить кэш React Query через invalidateQueries
- Добавить пропс onDelete в TaskColumn и TaskCard
- Использовать window.confirm() для подтверждения

## Критерии приёмки
- [ ] У каждой карточки есть кнопка удаления
- [ ] При клике появляется подтверждение
- [ ] После подтверждения карточка удаляется с сервера
- [ ] Карточка исчезает с доски без перезагрузки страницы
- [ ] После перезагрузки страницы удалённая карточка не возвращается
