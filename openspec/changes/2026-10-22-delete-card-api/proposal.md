# KAN-3: Удаление карточки на сервере

## Проблема
После переезда на свой сервер сломалось удаление карточек. Кнопка удаления на доске работала, пока данные отдавал мок. Сейчас карточка не удаляется, сервер отвечает 404 и возвращает HTML-страницу вместо JSON.

## Решение
Добавить на сервере Express роут DELETE /cards/:id для удаления карточки по ID из пути запроса. Добавить обработчик ошибок для неизвестных путей (возвращает JSON 404) и глобальный error-middleware (возвращает JSON 500).

## Технические детали
- Роут DELETE /cards/:id удаляет карточку из массива cards по ID
- При успешном удалении возвращает статус 200 и JSON с информацией
- При попытке удалить несуществующую карточку возвращает 404 и JSON
- Обработчик неизвестных путей возвращает JSON 404
- Error-middleware с 4 параметрами (err, req, res, next) возвращает JSON 500

## Критерии приёмки
- [ ] Удаление карточки работает с доски
- [ ] Карточка исчезает и не возвращается после F5
- [ ] ID карточки берётся из пути запроса, не из тела
- [ ] Удаление несуществующей карточки возвращает 404 JSON, не роняет сервер
- [ ] Запрос на неизвестный адрес возвращает JSON 404
- [ ] Error-middleware с 4 параметрами зарегистрирован после всех роутов
- [ ] Код клиента не изменён
