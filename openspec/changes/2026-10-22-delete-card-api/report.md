Изучена структура проекта:

- Клиент делает запросы через fetch на /api/cards
- В клиенте есть функция deleteCard (добавлена в теме 2)

2. Добавлен роут DELETE /api/cards/:id — удаляет карточку по ID из пути
3. Добавлен обработчик неизвестных путей — возвращает JSON 404
4. Добавлен error-middleware с 4 параметрами — возвращает JSON 500

## Технические детали

### Статус-код успешного удаления
Выбран 200 OK (стандартный код для успешных операций с возвращаемым телом).

### Обработка ошибок
- Неизвестный путь: JSON 404 {"error": "Маршрут не найден"}
- Удаление несуществующей карточки: JSON 404 {"error": "Карточка не найдена"}
- Внутренняя ошибка: JSON 500 {"error": "Внутренняя ошибка сервера"}
