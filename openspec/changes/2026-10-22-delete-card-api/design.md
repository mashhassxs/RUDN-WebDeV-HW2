# Design: Удаление карточки на сервере

## Архитектура
Сервер на Express с массивом карточек в памяти. Добавляем DELETE-роут и обработчики ошибок.

## Роуты
- GET /api/cards — получить все карточки (уже есть)
- DELETE /api/cards/:id — удалить карточку по ID (новый)

## Обработчики ошибок
1. Middleware для неизвестных путей — после всех роутов, возвращает JSON 404
2. Error-middleware с 4 параметрами (err, req, res, next) — в самом конце, возвращает JSON 500

## Структура ответа
Успех: { "message": "Карточка удалена", "id": "1" }
Ошибка 404: { "error": "Карточка не найдена" }
Ошибка 500: { "error": "Внутренняя ошибка сервера" }
